# R-52 2.12

Локальный ценовой радар: ядро, веб-интерфейс, сборщики товаров, история цен и фоновые задачи.

## Установка на Windows

Нужен Python 3.11 или новее. Склонируйте проект в путь без пробелов, например `C:\R52\R52-2.12`.

```powershell
python -m pip install -r requirements.txt
python -m playwright install chromium
.\R52-core.cmd
```

Для открытия интерфейса запустите `R52.cmd`. Ядро хранит данные в `%LOCALAPPDATA%\R52`; основная база — `data\r52.sqlite3`.

## Постоянная работа

`R52-core.cmd` запускает супервизор с автоматическим восстановлением ядра. Поместите ярлык на него в `shell:startup`. Автозапуск действует после входа пользователя в Windows.

При питании от сети:

```powershell
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
powercfg /change monitor-timeout-ac 15
```

Настройки UI для автосбора: приём без проверки включён, автосбор включён, нужный источник включён, широкий поиск включён, обновление цен 21600 секунд, лимит за цикл 20.

## Структура

- `r52/` — ядро, API, окно приложения, SQLite, сборщики и frontend; рабочие `r52/collectors/wb.py` и `r52/collectors/base.py` включены полностью.
- `tests/` — тесты.
- `collect/`, `debug/scripts/`, диагностические скрипты — разработка и диагностика сборщиков.
- `docs/` — техническая документация.
- `examples/` — безопасные шаблоны локальных настроек.

## Доступ к UI

Окно получает одноразовую ссылку через `POST /api/ui/session`, затем открывает `/ui/login?code=...`. Актуальный порт хранится в локальном `run/runtime.json`; health-эндпоинт — `/healthz`. Используйте `R52.cmd`, чтобы получить действующий сеанс.

## Что публикуется

Это исходный код системы, включая тесты, диагностику и сохранённые версии исходников. В `system-snapshot/` добавлен очищенный публичный снимок проекта и рабочих данных: базы, логи, история, входящие, резервные копии и выгрузки. Секреты доступа удалены; браузерные профили с закрытыми хранилищами и непроверяемые изображения/кэши остаются локально. Полный список исключений — `system-snapshot/SNAPSHOT-MANIFEST.json`. Исторические диагностические скрипты могут требовать собственного окружения и локальных образцов.

Сборщики экспериментальные: ответ площадки HTTP 403 возможен независимо от состояния ядра. Подробное описание и ограничения: [README-UPSTREAM.md](README-UPSTREAM.md).
