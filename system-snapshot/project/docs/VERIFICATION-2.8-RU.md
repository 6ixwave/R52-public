# Проверка R52 2.8.0

9 ноября 2026. Отдельная тестовая база; Linux, Python 3.13, Node 24, Chromium/Playwright с программным WebGL.

## Регрессии

- 89 Python-тестов: OK, 12,285 с. Схема базы остаётся 3.
- 59 JavaScript-тестов: пройдены, 0 ошибок. Шесть новых проверок покрывают непрерывность территорий, отсутствие промежутков/перекрытий, заполнение пустых районов декоративными зданиями, внутреннее положение подписей и реальных товаров, стабильность географии при фильтрации.
- Все невендорные JavaScript-файлы прошли синтаксическую проверку.
- Версия: R-52 2.8.0.

## Браузер и визуальная проверка

Восемь проверок/контрольных состояний: общий город, выбранный район, микрорайон с пятью настоящими товарами, отдалённый вид с ценовыми метками, пустой район с полноценной застройкой, нажатие названия непосредственно на карте, вращение камеры, узкий экран 390×844. Во всех состояниях подписи — геометрия в плоскости карты, а старых экранных плашек нет. Ошибок страницы и консоли в итоговом прогоне нет.

На тестовом наборе из шести товаров город содержит 1189 декоративных зданий. На полностью пустом каталоге — 1192; каждый из 33 районов содержит как минимум 26 зданий. Разница связана с резервированием мест под реальные объекты. Декорации не создают предложения и не меняют число товаров.

Проверено математически:

- Площадь суммы районов равна площади общего городского контура.
- Регулярная выборка точек общего контура принадлежит ровно одному району.
- Микрорайоны полностью делят родительскую территорию.
- Центр каждой подписи и все углы её плоскости находятся внутри своего участка.
- Фильтрация товаров не меняет полигоны и мировые точки привязки подписей.
- Настоящие товарные объекты остаются внутри своей подкатегории.

Во время разработки найдены и устранены повторяющиеся вершины границ, вызывавшие нечисловые радиусы и предупреждения графики. После исправления все 59 тестов и итоговый браузерный прогон прошли. Для подписей отключено дальнее затемнение туманом, чтобы текст оставался контрастным.

Общий вид и крупный район осмотрены на снимках реального интерфейса. Итоговый общий вид дополнительно экспортирован для статической визуальной проверки. При нехватке места надпись скрывается вместо искусственного смещения к другой территории. На самом далёком масштабе текст естественно становится мелким; для точного выбора остаётся список «Области».

## Границы проверки

Windows, отдельное окно Edge/Chrome, пользовательский GPU и FPS на нём не проверялись. Живые магазины, текущие цены, внешние видео и селекторы Eye в этой задаче не тестировались. Eye 0.7.0 включено без изменений.

Справочник 33 районов / 294 подкатегорий сохранён как объединённая основа основных товарных направлений, не полная актуальная выгрузка всех маркетплейсов. Тестовые данные, токены, профили, логи и снимки не включаются в поставку. Документы 2.7 описывают историческую проверку прежнего интерфейса и не заменяют этот отчёт.
