# Проверка R52 2.5

## Среда

Linux, Python 3.13, Node 24, Chromium с WebGL 2 через программный SwiftShader. Проверки выполнены на изолированной временной базе. Реальная пользовательская база не изменялась и не входила в сборку.

## Автоматические тесты

- **89 тестов Python — OK**, финальный прогон 12,870 с. Проверены API и локальная авторизация, миграции, сохранность данных, импорт, медиа, галереи, валидация, задачи, помощник и ограничение контекста карты, запуск/остановка ядра и сценарии сбоев.
- **30 тестов JavaScript — OK.** Прежние 21 тест модели/городской геометрии и 9 новых тестов экранной раскладки. Новые проверки охватывают один уровень подписей, пустую базу, монотонный ограниченный рост при отдалении, симметричное определение пересечений, отсутствие наложений и выхода за рамки, неизменную вместимость при изменении масштаба, центрирование последнего ряда, маленький экран и адресуемость всех товаров за пределами лимита декоративных зданий.
- Проверен синтаксис всех JavaScript-файлов приложения вне неизменённой vendor-папки.
- Команда версии возвращает R-52 2.5.0.

Повторение:

```
python -m unittest discover -s tests -v
node --test tests/*.test.mjs
```

Node нужен только для тестов JavaScript, не для запуска R52.

## Браузерная проверка

### Основной прогон — 17 контрольных точек

1280×770 и 390×844, набор из шести синтетических товаров, в том числе плотная группа видеокарт.

- Общий город и переход в категорию.
- Семь последовательных отдалений: карточки остаются, их размеры не уменьшаются; число видимых мест не сокращается.
- «Только город»: карточки и подписи остаются видимыми и интерактивными.
- Открытая карточка/галерея в обычном и тихом режимах; возвращение интерфейса Esc.
- Мобильная категория и галерея, режим уменьшенного движения.
- Переходы через обзор, товары, входящие, слежение, помощник, задачи, настройки, сервис и обратно на карту.
- Нет необработанных ошибок страницы и ошибок консоли. Проверено отсутствие горизонтального переполнения страницы и пересечений карточек.

### Расширенный прогон — 10 контрольных точек

1280×900 и 390×844, всего 106 синтетических товаров, из них 105 в категории техники.

- Последовательно пройдены **27 страниц**, открывающие **105 уникальных товаров**. Карточки не перекрываются, пагинация не перекрывается другими панелями.
- Галерея товара за пределами лимита 48 отдельных зданий открывается и восстанавливается после ухода в настройки и возврата на карту.
- На мобильном переключатель страниц доступен; в открытой карточке закрытие, «Подробнее» и «Спросить об этом» находятся внутри экрана и не закрыты другими элементами.
- Тихий режим сохраняет товары и подписи большой категории.
- Корневой мобильный вид сохраняет доступность пагинации рядом с управлением масштабом.
- Поиск без результатов показывает честное пустое состояние; изменение запроса возвращает товары.
- При принудительной потере WebGL-контекста появляется сообщение и остаётся доступен резервный список областей.
- Нет необработанных ошибок страницы и ошибок консоли в финальном прогоне.

## Визуальная проверка

Просмотрены отдельные PNG общего города, категории, дальнего масштаба, тихого режима, открытой карточки, мобильной категории/галереи, большой категории и мобильного корневого вида. По результатам исправлены перекрытие пагинации нижней панелью, конфликт мобильной пагинации с масштабом и уход действий раскрытой карточки за пределы экрана.

Дополнительно штатным HTML capture проверен сохранённый настоящий кадр приложения 1280×770: нет ошибок ресурсов, исключений, ошибок консоли или переполнения окна. PNG просмотрен отдельно. Диагностика отмечает фоновый декор и намеренное сокращение длинных названий до двух строк; полное название доступно в раскрытой карточке.

## Границы проверки

- Не проверялись установка и системное окно в настоящей Windows, аппаратная производительность и драйверы на компьютере пользователя.
- Не проверялись живые сайты маркетплейсов, актуальность всех селекторов Eye и воспроизведение стороннего видео в реальной сети. Eye 0.7.0 включён побайтно без изменений.
- Наборы данных для браузерных прогонов синтетические. При отсутствии импортированного фото показывается соответствующее сообщение, а не придуманное изображение.
- Это проверка перечисленных сценариев и регрессий, не обещание отсутствия любых ошибок во всех окружениях.

Схема базы остаётся 3. Логи, временная база, токены, браузерные профили и QA-снимки в дистрибутив не включены.
