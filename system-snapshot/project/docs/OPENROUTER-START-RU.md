# GPT‑5 Mini через OpenRouter — запуск

Это доработка R‑52 2.12.0. Установка дополнительных Python-пакетов не требуется.
По умолчанию остаётся прежний выбранный режим; OpenRouter сам не включается.

## 1. Перед обновлением

1. Полностью закройте R‑52 и остановите его ядро.
2. Сделайте резервную копию пользовательской папки R‑52 и базы.
3. Распакуйте этот архив в отдельную папку. Не запускайте одновременно старую и новую копии с одной пользовательской базой.
4. При открытии базы новая версия добавит миграции №4 и №5. Ранее применённые миграции не переписаны. После обновления не запускайте старый код на обновлённой базе; для отката восстановите резервную копию.

## 2. Ограничьте расходы

На сайте OpenRouter создайте отдельный API-ключ и установите для него лимит расходов $2 на первые испытания. Это нужно сделать самостоятельно: приложение не меняет настройки аккаунта OpenRouter.

В приложении локальный бюджет по умолчанию 200 центов ($2). Это НЕ строгий потолок списаний провайдера: неизвестные расходы, параллельные приложения и стоимость одного вызова могут отличаться от локального учёта. У каждой базы свой счётчик.

## 3. Задайте ключ в Windows

Откройте PowerShell в папке, где находится R52.cmd. Выполните, подставив собственный ключ вместо текста-заглушки:

```powershell
$env:OPENROUTER_API_KEY = 'ВСТАВЬТЕ_СВОЙ_КЛЮЧ'
.\R52.cmd
```

Переменная действует в этом PowerShell и запущенных из него процессах. После закрытия PowerShell её нужно задать снова. Не отправляйте ключ в чат и не сохраняйте его в исходниках. Если старое ядро уже запущено, оно не получит новую переменную — сначала полностью остановите его.

Для постоянной настройки используйте пользовательские переменные среды Windows: OPENROUTER_API_KEY. Затем заново откройте терминал и перезапустите приложение. Учтите, что переменные среды не являются защищённым хранилищем: другие программы вашего пользователя могут иметь к ним доступ.

## 4. Включите режим

Настройки → Помощник → Режим ответов → GPT‑5 Mini · OpenRouter.

Проверьте статус «Ключ задан». Это только наличие переменной, не проверка действительности ключа и не платный запрос.

Основная модель чата: openai/gpt-5-mini. В новой панели анализа дополнительно доступен Sonnet 4.5 только по отдельной подтверждённой кнопке. См. ANALYSIS-START-RU.md.

Выбранные сведения из локальной базы и ограниченная часть диалога отправляются OpenRouter и обслуживающему провайдеру. Не используйте облачный режим для данных, которые нельзя передавать внешним сервисам. Правила и Ollama остаются альтернативами.

## 5. Проверка

Откройте новый диалог и напишите свободный запрос, например:

«Помоги выбрать один из показанных вариантов. Что тебе нужно уточнить?»

Прямые команды «найди …», «избранное», «история цен …» и другие распознаваемые команды обычно выполняются правилами бесплатно. Для облачной проверки используйте свободную формулировку, а не только «статус».

При успешном вызове появится подпись GPT‑5 Mini · OpenRouter. Если модель разобрала команду, но итог составлен локальным кодом, подпись содержит «разбор команды». При ошибке будет ответ по правилам и пояснение.

После первого реального запроса сравните показанную стоимость с расходами в OpenRouter. Живые запросы при подготовке этого архива НЕ выполнялись.

## 6. Экономия и ограничения

- Максимум один платный вызов на пользовательское сообщение. Циклов агентов и повторной генерации нет.
- Стандартный выходной бюджет — 1400 токенов, включая рассуждения; reasoning effort low. Если модель не уложится в него, ответ отклоняется и показываются правила. Расход за такой вызов может сохраниться.
- В настройки можно поставить 512–3000 выходных токенов; повышение увеличивает возможные расходы.
- Модель возвращает один структурированный план: локальная функция ИЛИ короткий ответ по переданным фактам. После выполнения функции нет второго платного вызова для стилистического пересказа.
- Одно действие за сообщение. Составные поручения потребуют уточнения.
- Шесть последних сообщений, до 600 символов текста на сообщение; до пяти карточек вне выбранного контекста. Медиа и исходные выгрузки не отправляются.
- В режиме выбора товаров на карте передаются только выбранные товары, без истории общего диалога; изменение данных запрещено.
- Произвольные вычисления моделью запрещены. Для сравнения и истории используются существующие расчёты Python.
- Проверка чисел и привязка к карточкам не доказывают достоверность каждого словесного утверждения. Любая модель может ошибиться.
- Неизвестная стоимость показывается как неизвестная, а не $0. Для локального бюджетного контроля резервируется $0.10 на каждый вызов с неопределённой стоимостью, включая прерванные запросы. Автоматического сброса резервов нет: сначала проверьте расходы у провайдера. Локальный бюджет можно изменить вручную, осознавая неизвестные расходы.
- Повторы с тем же ключом не вызывают новую генерацию. После прерывания с неопределённым результатом платный повтор заблокирован. Проверьте историю и расходы, прежде чем сознательно создать новое сообщение.
- Статус расходов обновляется при повторном открытии настроек.
- Сервер использует только HTTPS openrouter.ai:443, проверяет сертификат и не следует перенаправлениям. Сетевое исключение действует только в потоке этого вызова; глобальные ограничения не отключены.

## 7. Что с Ollama

Она сохранена, но автоматически не устанавливается и не запускается.
Настройки → Помощник → Локальная модель Ollama — прежние модель и порт.
Настройки → Помощник → Только правила — без облачных обращений.
При ошибке OpenRouter нет автоматического перехода на другую модель: только ответ по правилам.

## 8. Тестирование без списаний

Из папки проекта:

```powershell
python -m unittest discover -s tests -p test_openrouter.py -v
```

Тесты используют временную базу, фиктивный ключ и подменённый HTTP-клиент. Они не требуют настоящего ключа и не обращаются к внешним моделям.
Результаты и ограничения — в OPENROUTER-VERIFICATION-RU.md.

## Диагностическое исправление 1

Это полный архив с диагностическим исправлением. После остановки ядра распакуйте его в отдельную папку и запустите оттуда с прежней переменной окружения. База и настройки не сбрасываются; новая миграция сверх №4 не добавлена.

«ты ИИ?» теперь получает бесплатный справочный ответ и НЕ проверяет OpenRouter. Чтобы получить причину ошибки подключения, после запуска отправьте один новый свободный вопрос о сохранённых товарах, например «Помоги выбрать среди сохранённых товаров, какие сведения тебе нужны?». При отказе будет виден код вида OPENROUTER_HTTP_404 и причина сервера либо отдельная сетевая ошибка. Перед передачей текста ошибки другим людям ещё раз проверьте отсутствие личных данных и секретов.
