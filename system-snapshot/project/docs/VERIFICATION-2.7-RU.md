# Проверка R52 2.7.0

Дата: 9 ноября 2026. Linux, Python 3.13, Node 24, Chromium/Playwright с программным WebGL. Использована отдельная тестовая папка данных, не пользовательская база.

## Автоматические проверки

- **89 Python-тестов — OK**, 9,899 с. Проверены существующие регрессии ядра, API, хранения, импорта, безопасности медиа и схемы базы. Схема остаётся 3.
- **53 JavaScript-теста — пройдены**, 0 ошибок. В том числе 14 новых проверок постоянного справочника, пустых участков, сохранения реальных путей категорий, стабильного размещения районов, ограничения размеров, перехода к ценовым меткам и защиты вложенных действий.
- Все невендорные JavaScript-файлы прошли синтаксическую проверку Node.
- Команда версии возвращает `R-52 2.7.0`.

## Браузер: 27 проверок и контрольных состояний

Основной сценарий — 19, дополнительные проверки разделов — 4, проверки настоящих локальных галерей — 4. Во всех трёх запусках: **0 необработанных ошибок страницы и 0 ошибок консоли**.

Проверены:

- Постоянная карта с 33 районами при шести реальных товарах; выбор пустого района «Книги» без создания товаров и без перекрывающей заглушки.
- Выбор «Техника → Видеокарты», пять связанных товаров, небольшие обычные карточки; восемь шагов отдаления → ценовые метки 76×34. Открытие галереи нажатием метки.
- Пустой результат поиска не удаляет 33 района и не закрывает карту глобальным сообщением.
- Один лист карточек скрывает ненужный переключатель страниц.
- Открытие входящего просмотра нажатием тела карточки; отсутствие отдельной кнопки «Открыть карточку».
- Повторное открытие через Enter/пробел, закрытие через Esc; очистка окна после закрытия.
- Раскрытие «Сведения и проверки» не открывает просмотр. Принятие тестового входящего файла выполняет только принятие, без случайного открытия.
- Добавление в избранное, выбор для сравнения и переключение фото не переходят в товар; нажатие тела товара переходит.
- Цель слежения открывает товар, её редактирование — своё окно. Нажатие сохранённого сравнения открывает сравнение. Удаление цели открывает подтверждение, не удаляя цель и не переходя в товар.
- Заголовок «Избранное» на обзоре открывает нужный раздел; строки задач и резервных копий раскрывают сведения. Просмотр резервной копии не восстанавливает данные.
- Все девять основных разделов открываются без ошибки маршрута.
- Узкий экран 390×844: две обычные карточки на странице, переход к небольшим ценовым меткам. В режиме «Только город» выбранные метки и подписи сохраняются.
- Уменьшенное движение ОС отключает переходы интерактивных объектов.
- Локальные двухкадровые галереи действительно загружаются во входящем просмотре. Их стрелки не запускают открытие родительской карточки.
- Увеличенный просмотр фотографии дважды открывается и сразу удаляется из документа при закрытии.

Визуально осмотрены общий город, пустой участок, карточки и дальние ценовые метки на широком/узком экране, входящий просмотр. Статический экспорт реальной сцены дополнительно отрендерен штатным помощником: нет исключений, ошибок консоли, неудачных ресурсов и выхода документа за границы окна. Ожидаемые сокращения длинных названий и декоративный фон отмечены диагностикой как локальное обрезание; это не горизонтальная прокрутка страницы. Полные названия доступны через подсказки и список областей.

## Исправления, найденные дополнительно

- Синхронная очистка входящего просмотра после закрытия: повторный Enter больше не зависит от отложенного события браузера.
- Аналогичная очистка увеличенного фото и явная активация медиа в новых окнах.
- Более близкий подлёт к небольшим промежуточным пользовательским категориям; прежний большой минимальный радиус мешал раскрытию глубокой иерархии. Синтаксис проверен; отдельный браузерный сценарий для произвольной многослойной пользовательской иерархии не выполнялся.
- Защита от экранных карточек при уходе выбранного участка из кадра. Логика добавлена; отдельный браузерный сценарий перемещения камеры с проверкой выхода участка за кадр не выполнялся.
- Нет декоративных кварталов по всей площади пустого справочника: они создаются около заполненных районов. Декоративные здания не являются дополнительными товарами.

Тестовые данные, фотографии-заглушки, секрет сеанса, логи, браузерные профили и результаты визуальной проверки в поставку не включены. Содержимое архива и контрольные суммы проверены отдельно при упаковке.
