# Проверка R52 2.6

## Среда и данные

Linux, Python 3.13, Node 24, Chromium с WebGL 2 через SwiftShader. База для браузерной проверки отдельная, синтетическая: 24 товара, 3 района, 8 микрорайонов. В выбранных «Видеокартах» — 5 товаров. Пользовательские данные не изменялись.

## Автоматические проверки

- **89 тестов Python: OK**, 10,500 с. API, авторизация, база и миграции, импорт, медиа/галереи, ядро и обработка сбоев.
- **39 тестов JavaScript: OK.** Включают прежние проверки модели и городских построений, адресуемость всех 105 товаров за пределами лимита 48 декоративных зданий и новые проверки пространственного интерфейса.
- Новые пространственные тесты: районы в дальнем виде, микрорайоны в ближнем, сохранение веса ветки при смене уровня, разные цвета соседних районов/микрорайонов, выбор самой глубокой реальной области по координатам, ограниченный рост небольших карточек, размещение шести привязанных к карте карточек без пересечений, мобильная пара карточек, честная пустая карта.
- Синтаксис JavaScript приложения проверен отдельно. Vendor-файлы не изменены.

Повторение из папки приложения:

```
python -m unittest discover -s tests -v
node --test tests/*.test.mjs
```

Node требуется только для тестов, не для запуска R52.

## Браузер: основной прогон

**9 состояний, без необработанных ошибок страницы и ошибок консоли.** Экраны 1440×900 и 390×844:

1. Общий город: подписи трёх районов на их координатах; нет полосы категорий в углу и товарной сетки.
2. Нажатие «Техника»: плавное приближение и названия микрорайонов, без чужих карточек.
3. Нажатие «Видеокарты»: пять карточек только этой подкатегории; ширина меньше 170 CSS-пикселей.
4. Отдаление: карточки увеличиваются, все пять остаются.
5. Приближение: карточки уменьшаются.
6. «Только город»: подписи и пять выбранных карточек сохраняются.
7. Открытие и закрытие полной карточки/галереи.
8. Мобильный вид: не более двух небольших карточек на странице.
9. Мобильная полная карточка, доступные кнопки и режим уменьшенного движения.

Дополнительно проверены записанные реальные прямоугольники карточек: пересечений между ними нет во всех девяти состояниях.

## Браузер: расширенный прогон

**6 сценариев, без необработанных ошибок страницы и ошибок консоли:**

- Приближение само, без выбора категории, меняет подписи районов на микрорайоны; карточки при этом не появляются.
- Обратное отдаление возвращает названия больших районов.
- Навигация район → микрорайон на мобильном. В мобильном общем виде видны все три названия районов.
- Мобильная пагинация открывает все пять уникальных товаров выбранной подкатегории.
- Пустой поисковый результат и восстановление каталога после очистки запроса.
- Девять маршрутов приложения и возврат в город без ошибки раздела.

## Визуальная проверка

Отдельно просмотрены кадры общего города, микрорайонов, выбранной подкатегории, отдаления, тихого режима, мобильных карточек/галереи, мобильного общего вида и микрорайонов. Исправлены первоначально слишком раннее переключение уровня и неполное помещение подписей районов в мобильном общем виде.

Стандартным HTML capture дополнительно отрендерен сохранённый настоящий кадр приложения 1440×900. Нет ошибок ресурсов, исключений и переполнения окна. PNG просмотрен отдельно. Диагностика фонового декоративного слоя не означает перекрытие интерактивных кнопок.

## Ограничения

Настоящая установка/системное окно Windows, аппаратные драйверы и FPS на компьютере пользователя не проверялись. Живые маркетплейсы, селекторы Eye и потоковое видео не проверялись повторно: Eye 0.7.0 включён побайтно без изменений. Отсутствующие фото в тестовой базе честно отмечены, изображения не придумывались.

Схема базы остаётся 3; новых миграций нет. Логи, тестовая база, токены, браузерные профили и служебные снимки в архив не включены. Отчёты более ранних версий — история, а не дополнительные проверки текущего выпуска.
