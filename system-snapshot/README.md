# Очищенный снимок установленной системы R-52

`project/` — файлы установленного проекта; `data/` — рабочая папка R-52, включая базу, историю, входящие и логи.

Секреты доступа заменены на `[REDACTED_AUTH_SECRET]`: токены, пароли, ключи, cookies авторизации и поля доступа прокси. Базы SQLite сняты через Backup API, очищены, выполнены VACUUM и integrity_check. ZIP-выгрузки переупакованы после очистки содержимого.

Браузерные профили с зашифрованными cookies/сеансами, исполняемые кэши и журналы SQLite не публикуются. Исходные файлы, комплект переноса и страховочные копии остаются локально без изменений.

Все исключения и результаты обработки перечислены в SNAPSHOT-MANIFEST.json. Это публичный диагностический снимок, а не резервная копия секретов. Наличие полей с REDACTED требует задать свои локальные доступы при восстановлении.
