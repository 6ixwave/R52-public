# Проверки перед публикацией

- `python -m compileall -q r52` — успешно.
- `python -m unittest discover -s tests -p "test_collector*.py" -v` — 31 тест, 11 failures и 1 error в текущем окружении Python 3.14.5.

Тесты сборщиков не проходят полностью; эта публикация сохраняет фактический код установленной версии и не заявляет устранение существующих ошибок. В выводе встречаются NETWORK_FORBIDDEN и сообщения ProactorEventLoop. Сборщики экспериментальные, доступность внешних площадок не гарантируется.

Проверка содержимого публичной копии: базы, runtime-токены, журналы, cookies, сохранённые прокси и профиль браузера исключены. Жёстко заданные адреса прокси в исторических диагностиках заменены адресами-примерами.
