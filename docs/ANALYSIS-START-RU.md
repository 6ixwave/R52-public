# R‑52: аналитик карточек, сравнение и проверка качества

Обновление интерфейса: см. UX-CITY-START-RU.md. Вкладки теперь только открывают сохранённые отчёты; новый расчёт запускается отдельной кнопкой.

## Обновление

1. Остановите старое приложение и ядро полностью.
2. Сделайте резервную копию пользовательских данных и SQLite-базы.
3. Распакуйте R52-2.12-City-Chat.zip в отдельную папку, не поверх пользовательской базы. Приложение использует прежнее место пользовательских данных; не запускайте две версии одновременно.
4. Запустите R52.cmd из PowerShell с прежней переменной OPENROUTER_API_KEY. Ключ в архив не включён. Если выбран другой профиль/папка данных, используйте прежние параметры запуска.
5. Схема базы обновится до миграции №6; миграции №1–5 не переписаны. Не запускайте старую версию на обновлённой базе. Для отката восстановите резервную копию.
6. Для платных режимов в Настройках выберите GPT‑5 Mini · OpenRouter. Режимы «Правила» и Ollama сохранены; аналитик не вызывает облако в обход выбранного режима.

## Где новые функции

### Карточка товара

Под основными сведениями добавлена панель «Анализ сохранённых данных»:

- «Проверить локально · бесплатно»: отчёт по сохранённой цене, типу цены, свежести и известным/неизвестным полям.
- «Разобрать с GPT‑5 Mini»: тот же набор фактов плюс короткие объяснения модели.
- «Углублённо · Sonnet 4.5»: отдельный необязательный платный запрос к anthropic/claude-sonnet-4.5. Не запускается автоматически. Это альтернативный разбор тех же фактов, а не второй агент, перепроверяющий первый.

Тренд объясняется только при достаточных наблюдениях с совпадающей известной модификацией и валютой. Анализ ограничен последними двадцатью датированными наблюдениями на карточку. При изменении обычной цены от 30% появляется сигнал для ручной проверки. Скрытые условия и применимость цены не подтверждаются автоматически.

### Выбранные товары

В «Товарах» отметьте карточки (до 12). В нижней панели:

- «ИИ-сравнение» — выберите критерий: обычная цена, минимальная показанная, свежесть или полнота.
- «Качество» — неизвестные поля, неизвестная свежесть/наличие, условные цены, возможные дубликаты по сходству названий. Разные модификации отмечаются как неподтверждённые совпадения, не объединяются.

Панель анализа также доступна под обычной таблицей сравнения, включая сохранённые списки. Неизвестная цена не становится нулевой. Разные валюты и типы цен не объединяются в один рейтинг. Даже минимум внутри группы не означает, что карточки идентичны по модификации или что товар стоит покупать.

«Полнота» считается по пяти полям: модификация, состояние, гарантия, доставка и комплектация. Полнота не доказывает достоверность.

### Справка

В «Помощнике» есть кнопка «Справка о характеристиках». Она объясняет общие понятия из знаний модели. Карточки и их история в этот запрос не передаются. В ответе явно написано, что это не сведения из вашей базы и не проверка конкретного товара.

## Что исправлено в чате

- Уточнение может содержать номер модели из переданных карточек: это больше не считается автоматически выдуманным числом.
- Уточняющий ответ сохраняет показанные карточки в контексте следующего сообщения.
- Если модель не прошла проверку, показываются понятный код/причина и доступная локальная сводка вместо нерелевантной справки «Не понял запрос».
- Проверки неизвестных товаров, выдуманных чисел, запрета записи без явной просьбы и выбранной области не отключены.
- Если точный пункт проверки неизвестен, показывается общий код INVALID_MODEL_OPERATION — не сырой ответ модели и не секреты.
- Приветствия и «ты ИИ?» по-прежнему локальные и бесплатные, не являются тестом подключения.

Точную причину прежнего отклонения из старой версии восстановить нельзя: она не сохранялась. Исправлены подтверждённые ограничения обработчика и добавлены диагностируемые отказы; это не гарантия, что любой ответ модели будет принят.

## Расходы и приватность

- Каждый запуск модели требует явного подтверждения в интерфейсе.
- Одна операция — максимум один платный запрос. Нет фонового анализа, каскада моделей, повторной генерации или автоматического перехода на Sonnet.
- Локальная проверка бесплатна. Чат может делать платные вызовы по прежним правилам режима OpenRouter.
- Бюджет базы общий для чата и новых разборов; прежний счётчик и неизвестные расходы сохранены.
- Перед вызовом резервируется $0.10 для Mini или $0.50 для Sonnet. Это НЕ цена и НЕ гарантированный потолок списания. При неизвестной стоимости резерв остаётся учтённым.
- По умолчанию локальный бюджет $2. Для первых проб используйте бесплатную проверку, затем один вызов Mini. Баланс $8 не требуется тратить целиком.
- Поставьте отдельный лимит ключа в OpenRouter. Локальный бюджет не заменяет ограничение у провайдера.
- В облако передаются ограниченные выбранные факты и вопрос, не вся база, фотографии или необработанные наблюдения. Не отправляйте конфиденциальные данные, которые нельзя передавать внешнему сервису.
- Повтор с тем же ключом не оплачивается заново: возвращается сохранённый результат или блокировка неопределённого запроса. Перезагрузка страницы/новый запуск панели создаёт новые ключи; новый подтверждённый запуск может быть платным.

## Проверки и ограничения

63 автономных теста: 37 прежних и 26 новых. Запуск из корня проекта:

```powershell
python -m unittest discover -s tests -p test_openrouter.py -v
python -m unittest discover -s tests -p test_analysis.py -v
```

Проверены синтаксис JavaScript, новые панели в Chromium на широком и узком экране, платные подтверждения и выбор модели на подменённом провайдере. Не выполнялись живые запросы GPT‑5 Mini или Sonnet, полный запуск настольного Windows-приложения, проверка всех маршрутов всей системы или списание вашего баланса.

Числа и структура ответа проверяются, но это не математическое доказательство всех смысловых утверждений модели. Сверяйте пояснения с раскрываемым списком фактов. Аналитик не меняет карточки, не объединяет дубликаты, не проверяет наличие/гарантию у продавца и не принимает решение о покупке за пользователя.
